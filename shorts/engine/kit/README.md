# Sandbox style kit (matches the two-colour big map + HUD overlay)

Colours
- China / defenders: tint rgb(70,120,215); bright #3d86ff (pawns); tag blue #2457c5; light text #8bb8ff
- Japan: tint rgb(215,78,55); bright #e0452c (pawns); tag red #d8312a; light text #ff8f74
- Front line between the two colours: cream glow #fff1c4
- Tag dark #101215, tag light #f7f4ee (text #14161a); highlight caption word #ffd84a

Fonts (files here, OFL)
- Bebas Neue: tags, big numbers, dates, chapter names
- Montserrat 700/900: captions, place names, card values

Sprites (transparent PNG, drawn by the same code as the map)
- pawn_{cn,jp}[_dead].png: soldier pawn (marching units)
- nato_{side}_{inf|armor|mech|art}_{2x|3x|4x}.png: unit counters, XX = division, XXX = corps/army group, XXXX = army
- tag_{red,blue,dark,light}.png: label styles (text is a sample)
- arrow_{cn,jp}.png: advance arrow look (gradient body, white chevrons, glowing tip)
